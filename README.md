### Calculadora de IMC em React

Esta é uma calculadora simples de Índice de Massa Corporal (IMC) construída com React e Vite. A aplicação permite que os usuários insiram sua altura e peso para calcular seu IMC e determinar sua categoria de peso.

## Funcionalidades

- Cálculo do IMC baseado na altura e peso informados
- Exibição da categoria de peso (abaixo do peso, peso normal, sobrepeso, etc.)
- Interface de usuário limpa e responsiva
- Cálculo em tempo real


## Instalação

Para executar este projeto localmente, siga estas etapas:

```shellscript
# Clone o repositório
git clone https://github.com/seu-usuario/IMC-REACT.git

# Navegue até o diretório do projeto
cd IMC-REACT

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## Como usar

1. Digite sua altura em metros (ex: 1,75)
2. Digite seu peso em quilogramas (ex: 70)
3. A aplicação calculará automaticamente seu IMC
4. O resultado mostrará o valor do seu IMC e a categoria de peso correspondente


## Categorias de IMC

- Abaixo de 18,5: Abaixo do peso
- 18,5 - 24,9: Peso normal
- 25,0 - 29,9: Sobrepeso
- 30,0 - 34,9: Obesidade Grau I
- 35,0 - 39,9: Obesidade Grau II
- 40,0 e acima: Obesidade Grau III
